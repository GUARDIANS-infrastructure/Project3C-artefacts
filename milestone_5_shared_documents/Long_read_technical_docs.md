## Long read technical resources

Long-read sequencing (LRS) standards are now available for data sharing through SeqHaven. 

The LRS Standards provide a well-characterised resource for the research community. The standards comprise 22 samples generated from mixtures of cancer and matched normal cell lines, spanning tumour purity levels from 0 to 100%. All samples were sequenced using the Oxford Nanopore PromethION P24 platform. The cell lines used to construct the standards include COLO829, COLO829_BL, HCC1937, and HCC1937_BL. 

These LRS Standards constitute a long-read dataset designed to support future research and tool development, including benchmarking. Technical documentation is accessible via the associated resource links.
